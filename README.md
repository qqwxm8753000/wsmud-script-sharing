> 武神MUD2 · 慕容碎磬机器人触发 / 脚本分享仓库

## ✨ 项目简介

本仓库收集并整理了适用于 **武神MUD2（wsmud）** 中 **慕容碎磬机器人** 的各类触发器（Trigger）与扩展（Extension）脚本，涵盖趣味娱乐、小游戏等实用功能，帮助玩家更轻松地使用机器人丰富游戏体验。

### 当前收录内容

| 分类 | 功能 | 说明 |
|------|------|------|
| `hitokoto` | 一言 | 随机发送精选名句 |
| `hitokoto` | 土味情话 | 随机发送土味情话 |
| `hitokoto` | 答案之书 | 占卜式趣味问答 |
| `small_game` | 猜数字 | 组队互动猜数字小游戏 |

## 🚀 使用流程

### 前置准备

1. 安装游戏脚本
2. 在武神MUD2游戏中打开机器人界面

### 第一步：添加触发器（Trigger）

1. 进入碎磬机器人 → **触发器管理**
2. 点击 **新建触发器**
3. 打开本仓库中对应的 `.txt` 文件，按照文件内的配置说明逐项填写：

| 配置项 | 说明 |
|--------|------|
| **名称** | 自定义，便于识别即可 |
| **频道** | 文件内标注的频道（如"世界"） |
| **发言人** | 通常留空 |
| **忽略发言人** | 一般填"自己名字"，避免自己触发自己 |
| **关键字** | 文件内指定的触发关键词 |
| **内容** | 粘贴文件内 `@js ...` 开头的代码部分 |

4. 保存并启用

### 第二步：添加扩展（Extension）

> ⚠️ **仅 `small_game` 等需要函数挂载的脚本需要此步骤，`hitokoto` 系列不需要。**

1. 进入碎磬机器人 → **扩展管理**
2. 点击 **新建扩展**
3. 将 `.txt` 文件内的**全部文本**粘贴到「扩展内容」中
4. **扩展内容填空格**（即内容区域留一个空格）
5. **位置填「动作栏」**
6. 扩展名称可自定义，用于挂载函数供触发器调用
7. 保存

### 第三步：验证

回到游戏，按触发条件测试（如在世界中发送对应指令），确认功能正常运作。

## 📖 各功能详细说明

### 🌸 一言系列（`hitokoto/`）

> 该文件夹下均为 **独立内容**，每个触发可单独使用，互不影响。

#### 一言
- **触发方式**：在世界频道发送指令后自动随机回复一句名句
- **数据来源**：[hitokoto.cn](https://v1.hitokoto.cn/) 公开API
- **效果**：`「名句内容」—— 出处作者 《作品名》`

#### 土味情话
- **触发方式**：在世界频道发送指令后随机回复一句土味情话
- **数据来源**：[oddfar.com](https://api.oddfar.com/yl/) 土味情话API
- **效果**：`「土味情话内容」`

#### 答案之书
- **触发方式**：在世界频道发送指令后随机回复一个答案
- **数据来源**：[60s.viki.moe](https://60s.viki.moe/) 答案之书API
- **效果**：`答案之书：「中文答案」 (English Answer)`

---

### 🎲 猜数字游戏（`small_game/guess_number/`）

> ⚠️ 该文件夹下为 **非独立内容**，完整运行需将 `trigger/` 和 `extension/` 下的文件 **全部添加**。

#### 游戏规则
1. **发起组队**：在世界频道发送"猜数字"关键词，机器人自动同意组队申请
2. **开始游戏**：组队成功后输入"开始猜数字"
3. **玩家竞猜**：队员在世界频道发送数字进行猜测
4. **结果排行**：游戏结束后，机器人公布每个人猜的数字与目标值的差距排行

#### 文件说明

| 文件 | 类型 | 作用 |
|------|------|------|
| `trigger/加入组队.txt` | 触发器 | 监听"猜数字"关键词，自动同意组队并加入游戏 |
| `trigger/猜数字.txt` | 触发器 | 监听游戏指令，驱动猜数字流程 |
| `extension/猜数字函数挂载.txt` | 扩展 | 挂载核心游戏逻辑函数 |
| `extension/队伍数字监听.txt` | 扩展 | 监听队伍成员发送的数字并比较 |

## ❓ 常见问题（FAQ）

**Q：触发器不生效？**
- 检查频道设置是否正确（世界/队伍/私聊）
- 确认「忽略发言人」已填自己名字
- 检查关键词是否完全匹配

**Q：扩展内容填什么？**
- 将 `.txt` 文件内全部文本粘贴到扩展内容框
- 然后**清空内容留一个空格**（这是碎磬机器人的特殊机制）
- 位置选择「动作栏」

**Q：API 请求失败 / 没有回复？**
- 检查浏览器是否能正常访问外网
- 部分API可能有跨域限制，建议切换浏览器尝试（推荐 Chrome / Edge）

**Q：hitokoto 和 small_game 能同时用吗？**
- 可以，两者互不冲突

## 🤝 贡献指南

欢迎提交你自己的触发器或扩展脚本！

1. **Fork** 本仓库
